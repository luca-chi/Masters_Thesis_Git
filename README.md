#  L. Chicos Master's Thesis GitHub directory

## Code

The MD simulations were performed using the HOOMD-blue tool. There are 3 main files for performing computational experiments: prepare.py is used for setting up the initial conditions of the simulation (creating a configuration file), simulation.py is used to run the actual simulation after having completed the initial setup, and analasys.py is an overarching code for extracting all analyzed values in the thesis.
